📝 To-Do App (Python)

A simple command-line To-Do App made using Python and file handling.

This project allows users to add, view, delete, and mark tasks as completed.


🚀 Features

✅ Add new tasks

✅ View all tasks

✅ Delete all tasks

✅ Mark tasks as completed

✅ File handling using .txt file

✅ Beginner-friendly Python project


📂 Project Structure

To-Do-App/

│

├── To-Do.py

├── To-Do_app.txt

└── README.md

▶️ How to Run

Install Python on your computer.

Clone this repository:

git clone https://github.com/your-username/To-Do-App.git

Open the project folder:

cd To-Do-App

Run the program:

python To-Do.py


📌 Menu Options

Enter (1) for Add task

Enter (2) for View task

Enter (3) for Delete task

Enter (4) for Mark task as completed

Enter (5) for Exit
